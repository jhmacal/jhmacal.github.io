# AI Governance Operating Model PDF Cover Package

This folder is a handoff package for designing a serious PDF cover for the AI Governance Operating Model.

Use these files:

- `designer-brief.md`: strategic direction, audience, tone, and visual boundaries.
- `cover-copy.md`: exact cover text and optional title-page text.
- `concept-prompt.md`: prompt to give a designer or use for visual exploration.
- `production-spec.md`: size, export, typography, and delivery requirements.

The target read is institutional, operator-grade, and legal. The cover should feel like a board-facing governance artifact, not a marketing brochure.
