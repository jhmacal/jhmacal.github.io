# Designer Brief

## Project

Design a PDF cover system for the AI Governance Playbook, a configurable operating model for AI governance.

## Audience

The reader is a legal, compliance, risk, privacy, security, procurement, or executive stakeholder evaluating whether the author can design an AI governance operating layer. The cover must create confidence before the reader reaches the substance.

## Desired Read

Serious. Institutional. Precise. Board-facing. Legal-operator. Quiet confidence.

The cover should feel closer to a governance manual, audit committee packet, regulatory playbook, or institutional white paper than a creator portfolio.

## Avoid

- Glossy gold cards.
- Startup AI gradients.
- Robot, circuit, neural-network, gavel, scales, courthouse, or generic tech imagery.
- Heavy decorative serif use.
- Fashion magazine cover energy.
- Sales-deck composition.
- Overly soft cream stationery.
- Dense prose on the cover.

## Visual Direction

Use restrained structure: rule lines, document bands, tabular alignment, margin discipline, and controlled negative space. The design should suggest a system that governs decisions, evidence, gates, escalation, and accountability.

Possible visual motifs:

- A thin rule grid that hints at a control map.
- A faint lifecycle path: intake, tiering, gates, registry, monitoring.
- A vertical document spine.
- A restrained institutional seal-like mark using only lines, not illustration.
- Subtle page architecture: section numbers, versioning, owner, review date.

## Brand Continuity

The cover should connect to jhmacal.com without looking like the website.

Core palette:

- Navy: `#0a1628`
- Ink: `#1c2834`
- Cream: `#f4ede0`
- Paper: `#fbfaf6`
- Gold accent: `#c9a961`
- Deep gold: `#a6822c`
- Muted grey: `#65707b`

Gold should be an accent, not the visual subject.

## Typography Direction

Use a serious serif for the title and a clean sans for metadata.

Good serif references:

- Times New Roman if the design goes intentionally legal-document.
- Tiempos Text.
- Mercury Text.
- Lyon Text.
- Chronicle Text.
- Canela only if used with restraint.

Good sans references:

- Inter.
- Suisse Int'l.
- Neue Haas Grotesk.
- Graphik.

The cover title must not look literary. It must look institutional.

## Cover Architecture

Recommended hierarchy:

1. Small label: `AI Governance & Legal Ops`
2. Main title: `AI Governance Playbook`
3. Subtitle: `An Operating Model for AI Governance`
4. Configuration line: company, sector, AI operating posture, markets
5. Version block: Version 1.0, owner, last reviewed
6. Author block: Julio Macedo, Senior Attorney | AI Governance & Legal Ops, jhmacal.com
7. Small disclaimer, preferably at bottom or inside title page

## Output

Design a cover that can support both the main playbook and annexes. The main cover can be more formal. Annex covers can use the same system with a smaller title and an `Annex A`, `Annex B`, or `Annex C` label.
